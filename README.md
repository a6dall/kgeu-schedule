# КГЭУ Расписание (KGEU Schedule Viewer) — 100% Чистый PHP

Веб-приложение и парсер расписания занятий Казанского государственного энергетического университета (КГЭУ), написанные **полностью на чистом PHP** (Server-Side Rendering) без использования JavaScript и Python.

---

## 🚀 Быстрый запуск

### 1. Веб-интерфейс
Запуск локального сервера одной командой:
```bash
php index.php
```
*Либо через встроенный сервер:*
```bash
php -S 0.0.0.0:8000 index.php
```
Сайт доступен в браузере по адресу `http://localhost:8000`.

### 2. Консольный просмотр (CLI на PHP)
Для быстрого вывода сетки пар прямо в терминале с ANSI-подсветкой:
```bash
php cli_view.php
```

### 3. Запуск в Docker
```bash
docker compose up -d --build
```

---

## ⚡ Особенности архитектуры
- **100% Чистый PHP**: Весь рендеринг страниц, навигация по календарю, фильтрация и управление задачами работают на стороне сервера (SSR).
- **Никаких сторонних языков**: удалены все файлы Python и JavaScript.
- **Подгрузка всего семестра**: быстрое параллельное скачивание расписания на все 18 недель семестра с сервера КГЭУ через PHP `curl_multi`.
- **Заметки и лабы**: отметка выполнения чекбоксами, переименование и удаление задач, добавление заметок к конкретным парам или ко всему дню.
- **Адаптивный дизайн**: поддержка темной и светлой темы, оптимизировано для смартфонов и ПК.
