# 🎓 КГЭУ Расписание (KGEU Schedule Viewer)

> Современное, быстрое веб-приложение для просмотра расписания и трекинга лабораторных работ студентов Казанского государственного энергетического университета (КГЭУ).  
> **Стек технологий:** **Vue.js 3** (клиентская реактивность без перезагрузок) + **100% Чистый PHP 8.3** (бэкенд, REST API и агрегатор расписания).

## 🏛 Архитектура проекта

Приложение построено по принципу **Single Page Application (SPA)** без тяжелых инструментов сборки (Webpack, Vite, Node.js). 

```
                               ┌──────────────────────────────────────────┐
                               │             Браузер (Клиент)             │
                               │  - Vue.js 3 (CDN, реактивное состояние)  │
                               │  - Tailwind CSS (стилизация интерфейса)  │
                               └────────────────────┬─────────────────────┘
                                                    │
                                     AJAX / fetch() │ JSON / Статика
                                                    ▼
                               ┌──────────────────────────────────────────┐
                               │           Бэкенд на Чистом PHP           │
                               │           (Файл: index.php)              │
                               │  - Встроенный CLI веб-сервер             │
                               │  - Роутер статики (/style.css, /app.js)  │
                               │  - REST API (/api/full-schedule, /todo)  │
                               └─────────┬──────────────────────┬─────────┘
                                         │                      │
                  Параллельный cURL (x18)│                      │ Чтение / Запись
                                         ▼                      ▼
                     ┌───────────────────────┐      ┌─────────────────────────┐
                     │ Официальный API КГЭУ  │      │       Файлы данных      │
                     │ (kabinet.kgeu.ru)     │      │ - data/schedule_...json │
                     └───────────────────────┘      │ - data/todo_state.json  │
                                                    └─────────────────────────┘
```

### Главные преимущества такой связки:
* **Мгновенный отклик интерфейса:** переключение дней, месяцев, выбор фильтров, чеканье лабораторных и заметок происходят реактивно в браузере через Vue.js 3 **без единой перезагрузки страницы**.
* **Никаких `node_modules`:** Vue 3 подключается одной строкой через CDN. Никаких `npm run build`, сборщиков и тяжелых зависимостей.
* **Надежное локальное хранение данных:** кастомные заметки, отметки о сдаче лаб и переименования сохраняются на бэкенде в чистый JSON (`data/todo_state.json`).
* **Молниеносный парсер расписания:** бэкенд на PHP использует `curl_multi` для одновременного скачивания всех 18 недель семестра за ~0.3 секунды и кэширует результат на диск.

## ⚙️ Как устроен бэкенд (`index.php`)

Файл [index.php](file:///Users/a6dall/VSC%20Projects/kgeu-schedule/index.php) выполняет 4 ключевые роли:

### 1. Запуск встроенного веб-сервера (CLI-режим)
Если запустить скрипт через `php index.php`, срабатывает условие:
```php
if (php_sapi_name() === 'cli') { ... }
```
PHP автоматически определяет хост и порт, запускает встроенный веб-сервер `php -S localhost:8000 index.php` и на macOS сразу открывает браузер.

### 2. Раздача статических файлов
Так как встроенный веб-сервер перенаправляет запросы в `index.php`, роутер перехватывает пути:
```php
if ($path === '/style.css') { ... }
if ($path === '/app.js') { ... }
```
И отдает их с корректными заголовками `Content-Type` и запретом кэширования (`Cache-Control: no-cache`), чтобы все изменения применялись моментально.

### 3. REST API эндпоинты
* **`GET /api/full-schedule?groupId=14493`**:
  - Проверяет наличие кэша `data/schedule_semester_14493.json`.
  - Если кэша нет или передан флаг `?force=1`, находит даты всех понедельников семестра (18 недель).
  - С помощью PHP `curl_multi` отправляет **18 параллельных HTTP-запросов** к `https://kabinet.kgeu.ru/api/Rasp`.
  - Объединяет все пары, сортирует их по дате и номеру пары, сохраняет кэш и отдает клиенту массив пар в формате JSON.
* **`GET /api/todo`**:
  - Возвращает JSON с состоянием чекбоксов, кастомных задач и переименованных лабораторных из `data/todo_state.json`.
* **`POST /api/todo`**:
  - Принимает измененный JSON от Vue 3 и атомарно записывает его в файл через `file_put_contents(..., LOCK_EX)`.

### 4. HTML-разметка с директивами Vue 3
Если запрошен корень `/`, скрипт отдает страницу, где подключены:
- `Vue.js 3` (через CDN);
- `Tailwind CSS` (утилитарные стили);
- Директивы Vue (`v-for`, `v-if`, `@click`, `v-model`), готовые к монтированию приложения.

## 🎨 Как устроен фронтенд (`app.js`)

Файл [app.js](file:///Users/a6dall/VSC%20Projects/kgeu-schedule/app.js) написан с использованием Vue.js 3 Composition API:

```javascript
const { createApp, ref, computed, onMounted } = Vue;
createApp({
  setup() { ... }
}).mount('#app');
```

### Ключевые реактивные переменные (`ref`):
* `selectedDate`: выбранный в календаре день (`YYYY-MM-DD`).
* `currentViewMode`: режим отображения (`'day'` — один день, `'week'` — вся неделя).
* `activeTypeFilter`: активный фильтр пар (`'all'`, `'lecture'`, `'lab'`, `'practice'`).
* `allPairsMap`: словарь всех занятий семестра, сгруппированных по дням.
* `todoData`: реактивный объект заметок и статусов сдачи.
* `modal`: состояние модального окна добавления/редактирования задач.

### Вычисляемые свойства (`computed`):
* `calendarDays`: генерирует сетку чисел для выбранного месяца календаря с отметками цветными точками (лекция, лаба, практика, экзамен).
* `activeSchedulePairs`: автоматически фильтрует пары текущего дня/недели по выбранному типу занятия. При смене фильтра или дня список обновляется мгновенно.

## 🚀 Запуск и разработка

### Локальный запуск на Mac:
В терминале перейти в папку проекта и выполнить:
```bash
cd "kgeu-schedule"
php index.php
```
Сервер запустится на `http://localhost:8000`, и вкладка автоматически откроется в Safari/Chrome.

## 🌐 Деплой на сервер (Docker + VPS)

На сервере проект запускается в изолированном Docker-контейнере на базе легкого Alpine Linux с PHP 8.3.

### 1. Как отправить изменения с Mac на GitHub:
```bash
git add -A
git commit -m "Update schedule features"
git push origin main
```

### 2. Как обновить сайт на VPS:
Благодаря пробросу каталога в [docker-compose.yml](file:///Users/a6dall/VSC%20Projects/kgeu-schedule/docker-compose.yml) (`./:/app`), достаточно просто подтянуть изменения из Git:
```bash
cd ~/kgeu-schedule
git pull origin main
```
После этого просто обновите страницу в браузере — все изменения в `index.php`, `app.js` и стилях вступят в силу немедленно!
