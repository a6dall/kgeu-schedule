# КГЭУ Расписание (KGEU Schedule Viewer)

Интерфейс и парсер расписания занятий Казанского государственного энергетического университета (КГЭУ) на основе API личного кабинета (`kabinet.kgeu.ru`).

---

## 🚀 Быстрый запуск

### 1. Веб-интерфейс (PHP)
Вы можете запустить локальный PHP-сервер одной командой:
```bash
php server.php
```
*Либо через встроенный веб-сервер:*
```bash
php -S localhost:8000 server.php
```
Сервер автоматически откроет страницу в браузере по адресу `http://localhost:8000`.

### 2. Консольный просмотр (CLI на PHP)
Для быстрого вывода сетки пар прямо в терминале с подсветкой:
```bash
php cli_view.php
```

*(Предыдущие скрипты на Python `server.py` и `cli_view.py` также сохранены для обратной совместимости)*

## 🔍 Структура данных запроса `Rasp`

Запрос `Rasp` возвращает JSON следующего вида:

```json
{
  "data": {
    "rasp": [
      {
        "код": 4782322,
        "дата": "2026-10-05T00:00:00",
        "начало": "13:20",
        "конец": "14:50",
        "деньНедели": 1,
        "день_недели": "Понедельник",
        "дисциплина": "лек Исследование операций",
        "преподаватель": "Филимонова Т.К.",
        "должность": "Доц",
        "аудитория": "Д604",
        "группа": "ПМ-1-24",
        "номерЗанятия": 4,
        "номерПодгруппы": 0,
        "цвет": "#008000"
      }
    ],
    "info": {
      "group": { "name": "ПМ-1-24", "groupID": 14493 },
      "year": "2026-2027",
      "curWeekNumber": 6,
      "curNumNed": 2
    }
  }
}
```

### Ключевые поля:
- **`дисциплина`**: содержит тип занятия в начале строки:
  - `лек ` — лекция;
  - `лаб ` — лабораторная работа;
  - `пр ` — практическое занятие.
- **`номерЗанятия`**: порядковый номер пары (1..6).
- **`начало` / `конец`**: точное время проведения пары.
- **`аудитория`**: кабинет (первая буква соответствует корпусу: «Д», «В», «А» и т.д.).
- **`номерПодгруппы`**: `0` — для всей группы; `1` / `2` — для подгрупп.

## ⚡ Возможности приложения

1. **Современный адаптивный UI**: чистый интерфейс, поддержка темной и светлой темы.
2. **Умная группировка по дням**: разделение пар по датам с указанием дня недели.
3. **Фильтрация и поиск**:
   - Фильтр по дням недели (Пн, Вт, Чт, Пт, Сб).
   - Фильтр по типу занятия (Все, Лекции, Лабораторные, Практики).
   - Мгновенный текстовый поиск по предмету, аудитории или преподавателю.
4. **Индикатор текущей пары**: живая подсветка занятия, если оно идет в текущую минуту.
5. **Экспорт в календарь (.ics)**: генерация файла календаря для добавления пар в Apple Calendar / Google Calendar на iPhone, Android или Mac в один клик.
6. **Ручной импорт**: встроенное модальное окно для вставки свежего JSON или загрузки файла.
